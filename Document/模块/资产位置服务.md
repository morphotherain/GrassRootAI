# 资产位置服务（AssetLocationService）

> **Domain**：Inventory / Data 交界  
> **代码**：`include/Sim/AssetLocation.h`、`include/Sim/IAssetLocationService.h`、`src/Sim/AssetLocationService.cpp`

## 为什么需要

`dynGameObjects.ContainerID` 历史上承担 **三种互不相同的语义**：

| 语义 | ContainerID 值 | 典型实体 |
|------|----------------|----------|
| **在空间中** | `0` | 出站后的船 |
| **在容器 bag 内** | `dynContainers.containerID` | 货舱物品、装备模块 |
| **停靠在建筑** | **建筑 objectID**（非 bag） | 进站后的船 |

若不显式区分，会出现：场景切换把「在货舱里的物品」误判为进站、AI 把 stationId 当 bagId 转移物品等问题。

**存档格式不变** — 仍读写同一列；服务层负责 **编码/解码** 与 **唯一写入口**。

---

## 核心类型

### AssetOwner

```cpp
AssetOwner::None()
AssetOwner::Character(pilotId)
owner.ToDynOwnerId()   // → dynGameObjects.OwnerID
AssetOwner::FromDynOwnerId(id)
```

将来扩展：`AssetOwnerKind::Corporation`。

### AssetLocation

```cpp
AssetLocation::InSpace(solarSystemId)
AssetLocation::InBag(bagId, contextSolarSystemId)
AssetLocation::DockedAt(structureObjectId, solarSystemId)
location.ToDynContainerId()  // → dynGameObjects.ContainerID
```

### 解码规则（ReadLocationFromDyn）

```text
ContainerID == 0        → Space
IsBagId(ContainerID)    → ContainerBag   // dynContainers 中存在该 bag
否则                    → DockedAtStructure
```

## API（IAssetLocationService）

| 方法 | 用途 |
|------|------|
| `ReadOwner` / `ReadLocation` | 从 dyn 读语义化结构 |
| `ResolveContextSolarSystemId` | 沿容器链推导星系（原 `BaseComponent::store` 逻辑） |
| `GetOrCreateBag(host, containerType)` | 替代散落的 `dynContainersManager` 调用 |
| `MoveToBag(objectId, bagId)` | 转移物品/装备（替代裸 `updateContainerID`） |
| `DockAtStructure(shipId, stationId)` | 进站 |
| `UndockToSpace(shipId)` | 出站（ContainerID→0） |
| `PersistFromBaseComponent` | 落库 + 写回推导后的 SolarSystemID |

入口：`GetAssetLocationService()`。

---

## BaseComponent 集成

| 旧用法 | 新用法 |
|--------|--------|
| `store()` 内手写 while 链 | `PersistFromBaseComponent` |
| `setContainerID` 表示进站 | `DockAtStructure` + `ApplyLocationToBase` |
| 读 `containerID != 0` 猜状态 | `GetAssetLocation().kind` |

`ownerID` / `containerID` / `solarSystemID` 字段 **保留**（内存缓存），新代码优先 typed API。

---

## 写代码规则

1. **改位置/归属** → 走 `GetAssetLocationService()`，禁止直接 `updateContainerIDByObjectID`（Service 内部除外）。
2. **场景切换** → 用 `AssetLocationKind`，禁止 `containerID != 0` 判断进站。
3. **新容器** → `GetOrCreateBag`，禁止复制 StorageComponent 里的 create 逻辑。
4. **Task transfer** → `TransferObjectHandler` 已改为 `MoveToBag`。
